# プラグイン体験改善の実装状況

更新日：2026-10-27 JST。対象版：0.9.0。

基準：[プラグイン体験仕様](PLUGIN-EXPERIENCE-SPEC.md)。新仕様の実装とローカルの通し確認を実施。本番反映・実ホスト受入は未実施であり、本番完了とは判定しない。

| 対象 | 実装・確認内容 |
|---|---|
| 通常見積 | prepare-estimate → preview-estimate → 本人用結果URLを標準化。再計算だけでは正常完了しない |
| 開始案内 | Web・30日保存・計算証明書・提供状態・ソース送信先を説明 |
| 数値専用契約 | 数値モデル、品質の数値集計と理由コード、通貨、スキル・測定規則版、照合hash。公開候補や自由記述説明は要求しない |
| 同意 | 対象読取と数値送信を分離。公式Webの本人認証・照合コード・選択操作で数値送信と15分表示を許可 |
| Intelligent UI | 開始・範囲・解析・確認・結果・失敗・ローカル終了を表示。MCP Apps resourceと状態表示ツール、ui/message・ui/open-linkを実装 |
| UI非対応 | スキルに同じ説明・ホスト選択式確認・公式Webリンクの代替を規定。実ホスト受入は残る |
| 本人用Web | 検査・再計算・円換算・照合から15分URLを返す。PARTIAL・暫定・TEST・未署名・未公開を表示 |
| 保存 | 同じ結果と換算時点を30日保存。既存の一覧・延長・削除を利用 |
| 復旧 | 入力を固定し同じ受付を保存。通信断後はresume-estimate。結果DTOもローカル保存 |
| 証明書 | 価値・制約・発行元・未提供を開始カードと結果に表示。署名・公開の本番提供は今回有効化しない |
| 配備確認 | 機能照会APIとDB構造確認を追加。0006未適用をリリース時に検出 |

証跡と本番反映手順は [0.9.0受入記録](PLUGIN-EXPERIENCE-0.9.0-ACCEPTANCE.md) を参照。ローカルの結合試験・ブラウザー確認は、実ChatGPT／Work／Codexのカード表示成功とは分ける。
