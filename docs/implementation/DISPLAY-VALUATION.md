# 表示時の為替換算と見積対象作業

更新日：2026-10-14  
状態：ローカル評価版0.2.0で固定Report v3・DisplayQuote v1・FRB取得・再表示を実装。`contracts/local-preview.schema.json`がローカル契約。Web画面・公開DTOへの接続は未実装。導入と実装範囲は[LOCAL-PLUGIN.md](../LOCAL-PLUGIN.md)を参照。

本書は、PH1-SPEC、ALGORITHMS、MCP-CHATGPT-PLUGIN、SHARED-SPEC、PLUGIN-IMPLEMENTATION、WEB-API-IMPLEMENTATION、IMPLEMENTATIONのうち、為替を見積時点に固定して通常表示する規定と、対象作業を詳細設計・単体テスト等に限定する規定に優先する。認証・公開同意・ソース保護の方針はPRODUCT-ARCHITECTUREを継続する。

## 1. 確定した方針

- 為替はFRB（Federal Reserve Board）のH.10公表データを直接取得する。第三者の為替APIを仲介しない。
- プラグインとWebの金額表示は、表示時に最新の取得可能なFRB公表レートで計算する。同じ見積りを後日再表示した場合も再計算する。
- 見積対象作業は「設計・実装・テスト」。企画と運用は含めない。
- 為替更新だけで、CFP・工数・基準USD額・採用済みの工数係数や時給を変更しない。

「表示時の時価」は本製品では表示時の公表為替による換算を指す。FRB H.10は日次観測値の週次公表であり、リアルタイムの取引レートではない。表示名は「表示時の参考換算額（FRB公表為替）」とし、観測日・公表日・確認日時を近接表示する。ソフトウェアの市場価値・販売価格という意味にしない。

この決定は、TEST工数係数・TEST時給を実績に基づく承認値に変更するものではない。TEST値を使った工数と金額は、為替が実データでもTEST試算と表示する。

## 2. 対象作業

| 区分 | 扱い |
| --- | --- |
| 設計 | 測定対象アプリケーションの設計を含む。詳細設計だけに限定しない。 |
| 実装 | 測定対象機能の実装を含む。 |
| テスト | 測定対象機能のテストを含む。単体テストだけに限定しない。 |
| 企画 | 事業・製品の企画等は含めない。 |
| 運用 | リリース後の運用、監視、日常の運用対応等は含めない。 |

従来の営業、顧客との要件交渉、組織管理、待ち時間、契約バッファ等の除外は継続する。対象作業と、ソフトウェアのどの機能を測定したかは別に表示する。「運用工数を除く」ことを理由に、アプリが備える監視機能や管理機能のCFPを一律に除外しない。

次期の作業範囲IDは `oes-design-implementation-test-v1` とする（実装上の版管理）。旧 `oes-functional-build-v1` とモックの `oes-standard-dev-v1` は説明範囲が異なるため、自動的に同一視しない。既存データは元の版を保持する。実績ベンチマークを採用する際は、この3作業の範囲と一致することを確認する。工程別工数の内訳や比率を根拠なく作らない。

## 3. 固定する評価と、表示のたびに計算する金額

| データ | 扱い |
| --- | --- |
| ソースsnapshot・Assessment・CFP・工数 | 評価記録として固定する。再測定は新しい評価。 |
| 工数係数・時給・作業範囲・基準USD額 | 評価に使用した版を固定する。表示のたびに最新の賃金へ差し替えない。 |
| 表示通貨・FRBレート・現地通貨額 | 表示要求時に解決し、計算する。 |
| 証明書・公開要約の署名 | 固定した評価と換算方針に対するもの。表示時換算額を過去に署名した金額と説明しない。 |

内部計算は以下とする。qはp25、median、p75。

```text
H_q = CFP × 保存済み工数係数_q
U_q = H_q × 保存済み時給USD
L_q(t) = U_q × 表示時に解決したcurrency_per_usd(t)
```

Lには表示用に丸めたUSD額を使わず、保存済みの計算根拠から再現した未丸めUを使う。Decimalの精度、逆数の小数12桁、通貨別の最終丸めはALGORITHMSの規定を継続する。USD表示ではレート1とし、FRB接続は不要。

次期契約は、固定した `Report / CalculationBasis` と、可変の `DisplayQuote` を分ける。

- ReportとCalculationBasisのhash対象には、表示時のFX・現地通貨額・表示時刻・FX取得失敗を含めない。
- DisplayQuoteには元評価を識別するhash、換算方針版、表示通貨、換算結果・状態、レート・方向、観測日、公表日、取得日時、最新確認日時、表示計算日時、出典URL、取得資料hashを持たせる。
- プラグインのtext・structuredContent、Webの主表示・内訳・印刷プレビューは、1回の表示要求で作成した同じDisplayQuoteを使う。
- 同じ評価を再表示してFXだけが変わっても、元評価のhash、評価ID、証明書ID、共有IDは変えない。新しい証明書発行や公開同意は発生しない。
- 過去の表示記録や印刷済みPDFはその時点の記録として保持できるが、現在の表示時換算額として再利用しない。既存の署名済みBundleは変更しない。

現行Report v1、旧Report v2設計、PublicEstimate v1の意味を同じ版のまま置換しない。実装時にSchema・domain・validator・projector・Skillを整合する新版に更新し、旧版の検証経路を分ける。

## 4. FRB直接取得と表示タイミング

固定取得先の初期値は `https://www.federalreserve.gov/releases/h10/current/`。通貨行、日付列、quote方向を検証し、形式変更を推測で補正しない。H.10のcountry seriesを追加する場合もFRBの許可URLを実装内に固定する。AIや閲覧ページから取得先URL・レートを指定させない。

- プラグインでは、新規評価の結果表示、保存済み評価の再表示、表示通貨の変更、明示的な再表示要求で再計算する。既に送信済みの会話メッセージは自動で書き換わらない。
- Webでは、ページ表示・再読込、明示的な更新、表示通貨の変更時に再計算する。開いたままの画面を常時更新する仕様は含めず、換算日時と更新操作を示す。
- 各表示要求でFRBの最新公表を再確認する。ETag/Last-Modifiedが使える場合は条件付き取得を使える。同時の取得要求はまとめる。以前の「6時間以内なら再確認せず利用する」方式は通常表示に採用しない。
- 正常な最新確認で公表値が変わらなければ、同じレートを再使用する。土日等で新しい観測がない場合も、観測日を隠さない。
- timeout5秒、応答上限5 MiB、固定許可先以外へのredirect拒否を初期実装条件とする。0・負数・未来日・ND・別通貨・quote方向不一致を拒否し、最新の有効な公表済み観測を選ぶ。
- プラグインではローカル実行部、Webではサーバーの共通FX adapterがFRBへ直接アクセスする。ブラウザへ任意URL取得能力を渡さない。為替要求にソースやAssessmentを含めない。

取得失敗時の状態は次のとおり。

| 条件 | 表示 |
| --- | --- |
| 最新確認成功、観測日から14暦日以内 | 表示時の参考換算額と観測日・確認日時。 |
| 最新確認失敗、14暦日以内の過去cacheあり | 過去cacheによる参考換算額と `FX_CACHE_AFTER_FAILURE`。「最新確認に失敗／前回取得レート」を表示し、最新確認済みとは扱わない。 |
| cacheなし | 現地通貨額null、`FX_UNAVAILABLE`。CFP・工数・USD額は維持。 |
| 観測日が15暦日以上前 | 現地通貨額null、`FX_STALE`。古い額を現在額として残さない。 |

14暦日は既存の運用上限を継続するもので、FRBが定めた値ではない。TEST固定為替へ黙ってフォールバックしない。自動試験では固定fixtureを注入し、外部接続を伴う動作確認と分ける。

## 5. 公開・署名・Webの整合

公開前の確認では、公開する固定評価・USDの基準額・使用する計算根拠とともに「円などの表示額は閲覧時のFRB公表為替で変わる」ことを説明する。同意対象とpreview_hashは固定部分と換算方針に結び付け、プレビュー時の円額だけに固定しない。FXだけの変化でプレビューを無効化しない。固定評価・係数・時給・metadata・換算方針を変える場合は再確認する。

公開用DisplayQuoteは公開許可済みの固定根拠から生成し、非公開の機能名、パス、ソースを含めない。非公開Report hashも公開せず、公開表示ではshare_idと固定公開payloadのhashに結び付ける。表示換算のために、現在のPublicEstimate Schemaへ無検査でfieldを追加しない。HTML全体の長期cacheで換算値が固定されないよう、固定公開記録とDisplayQuoteの取得・cacheを分ける。取得中・取得失敗・通貨切替で以前の額を新しい額として残さない。

印刷・ダウンロード・SNS文面を生成するときも、その生成操作時のDisplayQuoteを使い、観測日と換算日時を残す。OG画像は生成時点の換算額であることを明示する。SNS等の外部cacheや既に配布した画像は後から自動更新できるとは約束しない。Webページを開いたときの金額は改めて表示時換算する。
