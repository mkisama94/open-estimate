# 0.10.0 受入記録と残作業

全体完了は「実際の対応ホストで結果カード・PDFを確認し、一度の掲載同意と必要なログインだけで本人用保存URLへ到達し、応答消失後も再解析せず復旧できること」。ローカル試験だけで全体完了と判定しない。

## ローカルで検証する事項

- 保存済み結果からプレビュー・PDFを生成し、同意前にOpen Estimateへ通信しない。
- PDFは日本語を埋め込み、全体／部分と掲載前を区別し、ソース・詳細パスを含めない。
- 同意は内容hash・送信先・本人限定・30日・規約版・日時に固定され、再送は同じ操作IDと内容を使う。
- 所有者・期限・scope・署名・issuer/audience/clientを検証する。本人用Webで他所有者は404。延長・削除はCSRFとOriginを確認する。
- 連打・並行保存・応答消失で重複作成しない。数値・条件不一致は保存しない。
- PDF失敗・通信失敗でも元runと成果物を保持し、同じ結果から再生成・再掲載できる。
- 未送信の旧受付から自動送信せず、新規確認へ移行する。既存一時URL・保存済み結果と証明書系の互換性を保つ。
