# オープン工数見積 ローカル評価版 0.3.0

本書は旧版の記録です。0.4.0はローカルMCPを使いません。[新しい導入・検証手順](DESKTOP-PLUGIN.md)を参照してください。現在のplugin:packはdesktop-marketplaceを生成します。

現在のCodexプロジェクトのファイル構成を予備走査し、ユーザーが対象を確認してからコード本文を解析します。配布物に評価対象パスを固定しません。

## 更新・インストール

登録済みの Open Estimate Local から旧版をアンインストールし、0.3.0を再インストールしてアプリを再起動してください。マーケットプレイスの再登録は不要です。インストール先キャッシュを直接編集しないでください。

初回登録は PowerShellで以下を実行します。

    codex plugin marketplace add "C:\git\open-estimate\release\local-marketplace"

Node.js 24以降を使用します。配布物には実行時依存が入っていますが、このPCのNode実行パスを使います。別PCでは再ビルドしてください。

## 使用例

評価したいプロジェクトの新しいローカルチャットで、プラグインを指定し、次を依頼してください。

> Open Estimateで現在のプロジェクトを評価してください。まずファイル構成を走査して、対象範囲を確認してください。

1. get_assessor_contractで契約を取得。未選択のworkspace_root=nullは正常です。
2. discover_workspaceでファイル名・構成・種類・件数・除外例を取得します。本文、機能抽出、工数計算はまだ行いません。
3. AIが対象の絶対パスと走査結果を提示し、評価してよいか尋ねます。ユーザーは全体を承認するか、対象を絞れます。
4. 同意後、confirm_workspaceに候補IDを渡して確定。prepare_repository→read_repository_file→evaluate_assessmentへ進みます。
5. 評価IDを保存し、get_evaluationで再表示、render_reportで確認用HTMLを生成します。

MCP rootsが提供される場合は優先します。複数rootsを自動で1つに決めません。非対応ホストではCodexの現在の環境情報、または利用者が明示した絶対パスをcontext_pathへ渡し、conversation_context_unverifiedとして出所を表示します。MCPサーバーが会話の作業フォルダーを独立に証明したという意味ではありません。対象を特定できない場合だけ利用者に尋ねます。roots取得エラーは別パスへ自動フォールバックしません。

## 確認と範囲の扱い

確認前の本文読取り・見積り・保存済み評価取得はMCP側でも拒否します。候補の再走査、roots変更通知、サーバー再起動で確認は無効になります。旧snapshotも対象変更時に使えなくなります。roots非対応の場合やroots一覧に現れないアクティブプロジェクト変更はAIが検知して再走査します。同意フラグはAIによる利用者の回答の申告であり、独立した同意UIの証明ではありません。

予備走査は最大10,000項目・深さ20階層で打ち切りを表示します。依存、生成物、秘密情報ファイル、symlink等を除外。ファイル名に基づく分類のため、構成だけから機能の実装を断定しません。対象コードのビルド・実行・依存インストールは行いません。

対象を変更するための再パッケージ化は不要です。旧版の --workspace 指定は廃止しました。OES_WORKSPACE_ROOTもMCPの対象選択には使いません。

## 計算と為替

対象作業は設計・実装・テスト（企画・運用を除く）。2/3/5人時/CFPと50 USD/人時は架空TEST値、標本数0です。実績に基づく工数や納期の保証ではありません。

FRB H.10の公表ページを直接取得し、表示要求ごとに再確認します。CFP・工数・USD・report_hashは固定、現地通貨額のみ再換算します。日次観測の週次公表であり、取引市場のリアルタイム価格ではありません。取得失敗時は同じプロセス内の前回成功値を観測後14日以内なら警告付きで利用。それ以外は未算出。USD表示は接続不要です。生成済みHTMLは生成時点の記録であり、再生成すると最新公表為替で換算します。

## サンプルと検証

open-estimateプロジェクトで examples/quality-check を対象に確認後、評価します。手動基準はメモ登録3 CFP＋一覧取得3 CFP＝6 CFP。TEST中央値18人時、900 USDです。自動テストの手動Assessmentと、実際のAIによる抽出品質は別の確認です。

    npm run build
    npm test
    npm run plugin:pack
    npm run plugin:smoke

## 保存・実装範囲

評価JSONとHTMLはWindowsの %LOCALAPPDATA%\OpenEstimate\local-preview、ソースsnapshotは %TEMP%\open-estimate-snapshots に保存します。OES_STATE_DIR/OES_CACHE_ROOTで変更可能。暗号化・自動削除はありません。不要データはサーバー停止後に専用保存先を確認して削除してください。保存評価は同じ対象を再確認すれば、サーバー再起動後もIDで取得できます。

ソースをOpen Estimateの外部サーバーへ送る処理はありません。CodexのAI解析ではモデル提供元へコードが送信される場合があります。秘密情報の除外はファイル名等の規則であり、任意名のファイルの秘密を全検出するものではありません。

結果はローカル保存・未署名・未公開です。Web接続・証明書・公開・アカウント機能は今回の対象外です。
